\section{Token usage and cost of the test run}\label{app:cost}
The test run cost USD \CostTotal{} at batch prices, USD \CostPerRecord{} per record on average (median
\CostPerRecordMedian, maximum \CostPerRecordMax; Supplementary Fig.~\ref{fig:usage}c). Input averaged
\InputTokensMean{} tokens per record, because the prompt and the transcript so far were processed again after each code
run, and \CacheReadPct\% of input tokens were read from the prompt cache (cache writes accounted for
\CacheWriteCostPct\% of the cost).

Each record was sent as its own request through the Message Batches interface, which halves the price. The system
prompt was marked for prompt caching; the reported token counts show that the API also cached the context that grew
during each request's tool loop, so nearly all input tokens were cache writes or cache reads. Cost was computed from
the token counts the API reported for every request, at the list prices in the frozen configuration (USD 4 and 20 per
million input and output tokens, cache writes at 1.25 times the input price and cache reads at USD 0.20 per million
tokens, all halved for batches), which match the provider's published prices~\citep{anthropic2026pricing}. The
provider bills container time of the sandbox only beyond a monthly free allowance~\citep{anthropic2026pricing}; none
was charged, so the cost consists of tokens only.
